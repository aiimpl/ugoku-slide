# 別の目で見るレビュー

作った本人は、自分の意図で画面を読んでしまう。仕上げの前に、作り方を知らない別のエージェント（サブエージェント）に画像だけを見せて読んでもらう。

## 渡すもの

- `check/<名前>/NN.png`（全部出した状態）を全ページ分。HTML やこの会話は渡さない。
- 次の指示文をそのまま渡す。

```
あなたは初めてこの資料を見る【相手：例 役員】です。画像を1枚目から順に見て、次の4つに分けて指摘してください。
1. 日本語：読みにくい・意味が2通りに取れる・言葉がそろっていない所
2. 論理：見出しの主張と、図や数字が合っていない所。前のページとつながらない所
3. 破綻：数字の食い違い（見出しと本文、ページとページ）、合計が合わない所
4. 見た目：文字が重なる・切れる・小さすぎる・何を見ればいいか分からない所
各指摘は「何枚目・どこ・何がおかしいか・どう直すとよいか」を1行で。良い所は書かなくてよい。
```

## 受け取ったあと

指摘を表にして、1件ずつ採るか採らないかを決める。採らないときは理由を1行書く。

| No | 何枚目 | 分類 | 指摘 | 採否 | 理由・直し方 |
|---|---|---|---|---|---|
| 1 | 3 | 破綻 | 見出しは19億円、表の合計は18.6億円 | 採る | 表の数字に合わせて見出しを直す |
| 2 | 5 | 見た目 | 注記が小さい | 採らない | 雛形の大きさのまま（決まりの範囲） |

採った分だけ直し、`check.py` をもう一度通す。レビューは2回までで止める（回すほど、無難で弱い資料になる）。
