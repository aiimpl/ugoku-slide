# 雛形から資料を仕上げるときの決まり

雛形はどれも「架空の会社の、架空の数字」で作ってある見本。ここに書くのは、それを利用者の資料に作り替えるときの決まり。

## 中身

- 利用者の話と数字を使う。雛形に入っている会社名・人名・数字・日付は全部消す。
  - 消し忘れやすい所：`<title>`、`<meta name="description">`、先頭コメントの「このスライド：…」、
    CSS の中に書かれた数字（例：`width:calc(142.6 / 360 * 100%)` のような、グラフの長さを決める値）、
    `data-count="…"` の値、`data-calc` の `value` と `data-let` の式の中の定数、発表者メモ。
- 足りない数字を作ったときは、作ったことを利用者に伝え、スライドにも「仮の数字」と書く（ページの足元や、数字の横の小さな札）。
  雛形の「数字は架空のサンプルです」は、仮の数字が残るなら「仮の数字を含みます」に、全部が本物なら消す。
- 1枚に言いたいことは1つ。見出しは結論の一文（「売上推移」ではなく「売上は3か月連続で伸びた」）。
- 見出しが数字を言い切っていて、その数字をスライダーで動かせるなら、見出しも式で出す
  （`data-out` の式が文字を返すと、その文字がそのまま出る。例：`data-out="m >= 30 ? '3年で回収できる' : '3年では回収できない'"`）。
  文字を返したときは `data-unit` は付かないので、単位は文字の中に書く。
  見出しが `data-calc` の箱の外にあるときは、`data-calc` と `data-let` をその `<section class="slide">` に移す（ページ全体が1つの計算の箱になり、見出しの `data-out` も動く）。
  表（`data-sheet`）の数字で見出しを変えるときは、見出しを `<figure data-sheet>` の中に入れて `data-sheet-out` で書く（54 の3〜5枚目が見本）。
- 計算で答えが出ないとき（赤字・0で割る など）は、式から文字を返して意味を書く（例：`'手残りが出ない'`）。
  数にならない答えは「—」と出て、check.py は「計算できない式」として知らせる。
- 発表者メモ `<aside class="notes">` を各スライドに付ける。
- 最後のページは、決めてほしいこと・次の一歩・問い合わせ先 のどれかで締める。

## 文字の大きさ

- 説明の文・箇条書き・表の中身は 18px 以上。
- 見出しの上の小さな見出し（kicker）、ページ番号、出典や注記、グラフの目盛りと項目名、根拠（details.why）を開いた中の文、
  つまみの名前、カードの中の短い補足は、雛形の大きさのままでよい（雛形より小さくはしない）。
- 1280×720 からはみ出さない。雛形より文字を増やすと溢れるので、増やしたら画像で確かめる。

## 作りの読み方と、書き換える場所

雛形は2種類の作り方が混ざっている。書き換える前に、そのページがどちらかを見る。

1. **流れで並ぶページ**（`.grid` `.cols-3` `.split` などで並ぶ）：文字と数字を差し替えるだけでよい。
2. **座標で置いたページ**（2つ目の `<style>` に `.s-market .core{left:…;top:…;width:…}` のような指定があるページ）：
   図形の位置・大きさは CSS に書いてある。棒の本数や長さ、円の大きさが変わるなら、その CSS も計算し直す。
   例：3本の棒の高さが売上に比例しているなら、利用者の売上で高さ（px）を比で出し直す。数字の札の位置も棒に合わせて動かす。

- 色と書体は 2つ目の `<style>` の `:root`（`--accent` など）で変える。ブランドの色を頼まれたら、まずここだけを差し替える。
- 「ugoku-slide engine」の BEGIN〜END は変えない。
- 雛形ごとに独自の class がある（例：変形する背景の板を `.plate` や `.pc` と呼ぶ、あとから出す要素に `.in` を付けて `data-enter="none"` と組む）。
  部品の一覧（parts.md）に無い class は、その雛形の中の使われ方をまねる。新しく作るより、既にある要素を写して使う。

## 変形（data-morph）でつなぐとき

- 前後のページで同じ `data-morph="名前"` の要素が、位置・大きさ・色を保ったまま変形してつながる。
  同じ名前は、同じもの（この事業・この店・この工程）を表すこと。筋書き（同じものが形を変えて続く）を残して中身を差し替える。
- 名前が次のページに無ければ、変形はせず普通に消える／現れる。間のページで一度消えた名前は、その次のページでは変形せずに現れる。
- 文字の入った箱を変形させるときは、背景だけの要素（`position:absolute;inset:0`）に `data-morph` を付け、中の文字は `data-morph-enter` であとから出す。
  1語の文字（数字など）はそのまま `data-morph` を付けてよい。数字に `data-count` があると、前の値から数え直す。
- 位置は left/top・grid・flex で決める。transform で位置を動かさない（変形が狂う）。
- 大きさが大きく変わる先（大きな箱 → 細い帯）は、枠線なしの塗りにする。変形の途中で枠線が太って見える。
- `data-calc` の箱の中の要素にも `data-morph` は付けられる（CSS 変数で大きさが変わる図形のまま、次のページへつながる）。
- 回せる立体（`data-orbit`）の中の要素は、変形でページの外へつなげない。

  - `NN-0.png`（→ を押す前）で、画面の下半分が空きすぎていないか
  - `NN-why.png`（根拠を全部開いた状態）で、開いた中身が図を潰したり隠したりしていないか
