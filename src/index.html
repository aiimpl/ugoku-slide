使い方（ターミナル不要・3ステップ）

Claude のデスクトップアプリでも、ブラウザの claude.ai でも同じです。

雛形をダウンロード

下の一覧から好きなデザインの「ダウンロード」を押す。ダブルクリックすればブラウザでそのまま動きます。

Claude に渡して頼む

ファイルをチャットにドラッグして、「Claude用の指示をコピー」で写した文を貼り、テーマと数字を書き足して送る。

プレビューで直して保存

出てきた HTML をその場で確かめ、「3枚目の文字を大きく」のように話しかけて直す。できたらダウンロード。

Claude のスキルとして入れる

入れておけば、ファイルを渡さなくても「動くスライドで、〇〇の資料を作って」と頼むだけで、{{COUNT}} 種から場面に合う雛形を選んで作ります。

claude.ai・デスクトップアプリ

  1. ugoku-slide-skill.zip をダウンロード（解凍しない）
  2. Settings → Capabilities で Code execution（コードの実行）をオンにする
  3. Customize → Skills →「＋」→ Upload a skill で、zip をそのまま選ぶ
スキルをダウンロード

Claude Code

  1. zip を解凍して、できた ugoku-slide フォルダを ~/.claude/skills/ に置く
  2. 「動くスライドで、来期の採用計画を役員会向けに作って」のように頼む
  3. できた HTML を開いて確かめ、話しかけて直す（同梱の scripts/check.py で崩れも確かめられる）

中身：SKILL.md（作り方）・雛形 {{COUNT}} 本・部品と決まりの説明・確かめるスクリプト。MIT。

Claude への頼み方

雛形のファイルを添付して、そのまま貼って使えます。【 】の中を書き換えてください。

添付の HTML は「動くスライド」の雛形です。
先頭のコメントに書かれた部品とルールだけを使って、次の内容のスライドに作り替えてください。
・1ファイルのまま。「ugoku-slide engine」の BEGIN〜END の中は変えない
・デザイン（2つ目の <style>）はそのまま活かす
・1枚に言いたいことは1つ。文字は少なめに
・数字の話は data-calc で、見る人が動かして確かめられるように
・根拠や補足は <details class="why"> に入れる
・各スライドに発表者メモ（<aside class="notes">）を付ける
・完成したら HTML の全文を出す

テーマ：【例）来期の採用計画】
見せる相手：【例）役員会】
いちばん伝えたい結論：【例）エンジニアを12人増やせば、開発の遅れが解消する】
使いたい数字：【例）今の人数 38人、1人あたりの採用費 120万円、遅れている案件 9件】
枚数：【7枚くらい】

あとから足す

【4】枚目に、【単価】と【数量】を動かすと
【売上】が再計算されるシミュレーターを足して。
各スライドの主張に、クリックで開く
「根拠」を付けて。出典や計算式を中に書いて。

色を会社のコーポレートカラー【#0055aa】に合わせて。

これを【10分】で話せるように、枚数を調整して、
発表者メモに話す内容と目安の秒数を書いて。

よくある質問

本当に無料？ 仕事で使っていい？

無料です。MIT ライセンスなので、社内資料・商談・研修・販売物への組み込みまで自由に使えます。クレジット表記も不要です（ファイル先頭のコメントは残してもらえると嬉しいです）。

インターネットがないと動かない？

動きます。仕組みはすべてファイルの中に入っています。ネットから読むのはフォントだけで、つながらないときはパソコンにある文字で表示されます。

PowerPoint で渡したいと言われたら？

ブラウザの印刷から「PDF に保存」すると、1ページ1枚のきれいな PDF になります（クリックで開く補足も開いた状態で出ます）。PowerPoint で編集できる形にはなりませんが、PDF なら PowerPoint にも挿入できます。

相手のパソコンやスマホでも見られる？

Chrome・Edge・Safari・Firefox の最近の版で動きます。画面の大きさに合わせて 16:9 のまま拡大縮小するので、レイアウトは崩れません。スマホは横向きで、左右にスワイプするとページが送れます。

第1弾で作ったスライドにも、変形する動きを足せる？

足せます。第2弾の雛形を1本 Claude に一緒に渡して「この雛形の data-morph の使い方をまねて、〇枚目から〇枚目の図形を変形でつなげて」と頼んでください。仕組みは全部の雛形で共通なので、今回のダウンロードからは第1弾の50本にも入っています。

スキルと、ファイルを渡すのは何がちがう？

できるスライドは同じです。スキルを入れると、毎回ファイルを添付しなくても、Claude が {{COUNT}} 種の説明を読んで場面に合う雛形を選び、作り終えたら崩れを確かめるところまでやります。

直したい所を、どう Claude に伝えればいい？

スライドを開いて E を押し、直したい所をドラッグで囲んで「文字を大きく」のように書きます。「指示をコピー」を押すと、何枚目のどの範囲か（座標と、中に入っている文字）つきの指示ができるので、Claude に貼るだけです。

HTML が分からなくても直せる？

Claude に頼めば直せます。各ファイルの先頭に「使える部品と書き方」の説明が入っているので、Claude はそれを読んで同じ作りのまま中身を書き換えます。
