Claude への頼み方

雛形のファイルを添付して、そのまま貼って使えます。【 】の中を書き換えてください。

添付の HTML は「動くスライド」の雛形です。
先頭のコメントに書かれた部品とルールだけを使って、次の内容のスライドに作り替えてください。
・1ファイルのまま。「ugoku-slide engine」の BEGIN〜END の中は変えない
・デザイン（2つ目の <style>）はそのまま活かす
・1枚に言いたいことは1つ。文字は少なめに
・数字の話は data-calc で、見る人が動かして確かめられるように
・根拠や補足は <details class="why"> に入れる
・各スライドに発表者メモ（<aside class="notes">）を付ける
・完成したら HTML の全文を出す

テーマ：【例）来期の採用計画】
見せる相手：【例）役員会】

使いたい数字：【例）今の人数 38人、1人あたりの採用費 120万円、遅れている案件 9件】

【4】枚目に、【単価】と【数量】を動かすと

各スライドの主張に、クリックで開く

よくある質問

本当に無料？ 仕事で使っていい？

無料です。MIT ライセンスなので、社内資料・商談・研修・販売物への組み込みまで自由に使えます。クレジット表記も不要です（ファイル先頭のコメントは残してもらえると嬉しいです）。

インターネットがないと動かない？

動きます。仕組みはすべてファイルの中に入っています。ネットから読むのはフォントだけで、つながらないときはパソコンにある文字で表示されます。

PowerPoint で渡したいと言われたら？

ブラウザの印刷から「PDF に保存」すると、1ページ1枚のきれいな PDF になります（クリックで開く補足も開いた状態で出ます）。PowerPoint で編集できる形にはなりませんが、PDF なら PowerPoint にも挿入できます。

相手のパソコンやスマホでも見られる？

Chrome・Edge・Safari・Firefox の最近の版で動きます。画面の大きさに合わせて 16:9 のまま拡大縮小するので、レイアウトは崩れません。スマホは横向きで、左右にスワイプするとページが送れます。

HTML が分からなくても直せる？

Claude に頼めば直せます。各ファイルの先頭に「使える部品と書き方」の説明が入っているので、Claude はそれを読んで同じ作りのまま中身を書き換えます。
