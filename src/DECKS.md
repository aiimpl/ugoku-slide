# 雛形の作り方（新しいデザインを足すとき）

1本の雛形は `src/decks/NN-名前.html` の1ファイル。`make build` で共通の仕組み（`engine/`）と合体して、
`docs/slides/NN-名前.html` に「それだけで動く1ファイル」として書き出される。

## ファイルの形

```html
<!--meta
{"title":"ブラウザのタブに出る題名","style":"デザインの名前","use":"向いている用途","group":"分類",
 "aim":"誰が・どんな場面で・何のために使うか（1文）",
 "desc":"一覧に出る説明（70字くらい）。何が動くかを1つ入れる。",
 "fonts":"https://fonts.googleapis.com/css2?family=...&display=swap"}
-->
<style>
:root{ --bg:…; --surface:…; --ink:…; --muted:…; --line:…; --accent:…; --accent-ink:…; --frame:…; --font:…; }
/* このデザインだけの飾りと部品の見た目 */
</style>

<main class="deck" data-transition="fade">
  <section class="slide cover" data-title="表紙"> … <aside class="notes">発表者メモ</aside></section>
  …
</main>
```

- `group` は次のどれか：`ビジネス定番` `ミニマル・タイポ` `和・ナチュラル` `レトロ・ポップ` `テック・未来` `データ・図解` `学び・研修`
  第2弾（51〜）は `一続きに動く` `触れる・立体` `表から作る` も使える。
- `fonts` は Google Fonts だけ（2書体まで）。`--font` には必ず日本語の代わりの書体（Hiragino Sans など）も続けて書く。
  ネットがなくても崩れないこと。
- 画像ファイル・外部の CSS/JS は使わない。飾りは CSS（グラデーション・模様・影）とインラインの SVG（data URI 可）で描く。

## 中身の決まり

- 狙い（aim）は1つの場面に絞る。「何にでも使える」寄せ集めにしない。その場面の人がそのまま使える中身にする。

- 6〜8枚。1枚目は表紙、最後は締め（決めてほしいこと・次の一歩・問い合わせ など）。
- 1枚に言いたいことは1つ。見出しは「結論の一文」にする（「売上推移」ではなく「売上は3か月連続で伸びた」）。
- 本文は 18px 以上。1280×720 の枠からはみ出さない。下半分が空かないよう、文字や数字を大きく使って画面を埋める。
- 次を必ず入れる
  - `.step`（→ で順番に出る）を1か所以上
  - `<details class="why">`（クリックで根拠）を1か所以上
  - `data-calc`（スライダー2つ以上 → 意味のある計算）を1か所以上
  - さらに `data-tabs` `data-rank` `.quiz` `.chart` `pre.code` `data-count` のどれか1つ以上
  - `<aside class="notes">` を3枚以上
- 会社名・人名・数字はすべて架空（「サンプル商事」など）。実在のブランド・人物・ロゴは出さない。
  どこかに「数字は架空のサンプルです」と入れる。

## デザインの決まり

- 配って恥ずかしいものは出さない。その様式の第一線のデザイナーが作ったと言える水準にする。
  安っぽく見える要素（絵文字の多用、単色背景に白いカードを置いただけ、ありがちなグラデーション、中途半端な飾り、
  詰め込み、小さすぎる文字、揃っていない余白）は使わない。書体・字間・行間・大きさの対比・余白・配色の比率を詰める。

- 名前のデザインらしさが、表紙を見た瞬間に分かること。色・書体・余白・飾り・部品（カード、タブ、スライダー、
  補足、クイズの選択肢、棒グラフ）の見た目まで、そのデザインの作法で塗り替える。
- 文字と背景のコントラストは WCAG AA 以上。
- 動きはスライドの切り替え（`data-transition`）と、そのデザインに合う控えめな飾りのアニメーションまで。
  ずっと動く飾りは `@media (prefers-reduced-motion:reduce)` で止める。
- `engine/` の中は書き換えない。部品の見た目はテーマの `<style>` で上書きする。

## 第2弾（51〜）の決まり

第2弾は「めくっても途切れない・触ると形が変わる」が主役。次のどれか1つを、その雛形の芯にする（おまけで足さない）。

- `data-morph`：ページをまたいで同じ要素が変形してつながる（`data-transition="morph"`）
- `data-calc` の CSS 変数：スライダーで数字だけでなく、図形の大きさ・位置・色が動く
- `data-orbit`：ドラッグで回せる立体・分解図
- `data-sheet`：表を直す・貼ると、グラフと集計が作り直される
- `.draw`：線が描かれて図が組み上がる

### data-morph のコツ（守らないと途中で崩れる）

- 変形させる要素は HTML の要素にする（SVG の中の要素は変形しない）。位置は left/top・grid・flex で決め、transform で動かさない。
- 同じ名前の要素は、前後のページで「同じもの」を表すこと（例：表紙の丸 → 市場の円 → 3年目の棒は、ずっと「この事業」）。
- 文字の入った箱を変形させるときは、背景だけの要素（例 `.plate`、`position:absolute;inset:0`）に `data-morph` を付け、
  中の文字は `data-morph-enter` であとから出す。文字ごと変形させると、途中で文字が伸びる。
- 1語の文字（数字・見出しの一部）は、そのまま `data-morph` を付けてよい（span などは自動で inline-block になる）。縦横比を保って動く。数字に `data-count` があると、前の値から数え直す。
- `data-morph` を含む箱には、ページを開いたときのふわっと出る動きが付かない。その箱の中の変形しない要素には `data-morph-enter` を付ける。
- 背景の模様やグラデーションは `.slide` ではなく `.deck` に付ける（`.slide` に付けると、前のページが一瞬で消えて見える）。
- 大きさが大きく変わる先（大きな箱 → 細い帯など）は、枠線なしの塗りにする。変形は拡大縮小なので、途中で枠線も太る。
- data-orbit（3D）の中の要素は data-morph で外へつなげない。途中で平たい板になる。立体の外に置いた平面の要素どうしでつなぐ。
- 確かめるときは、ページ送りの途中（0.1・0.25・0.45 秒）のコマも見る。途中で形が消える・跳ぶ・重なって読めない、は直す。
